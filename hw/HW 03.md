# 3. Добавьте внешний диск к виртуальной машине и перенесите туда базу данных.
1. Создаем папку
```
sudo mkdir /mnt/pg-ext-data
```
2. Смотрим список дисков
```
lsblk
NAME    MAJ:MIN RM  SIZE RO TYPE MOUNTPOINTS
vda     253:0    0   20G  0 disk
├─vda1  253:1    0 19.4G  0 part /
├─vda14 253:14   0    4M  0 part
└─vda15 253:15   0  600M  0 part /boot/efi
vdb     253:16   0    5G  0 disk
```

3. Создадим файловую систему на диске, созданном на этапе 1 (диск на 5GB)
```
sudo mkfs.ext4 /dev/vdb
```

4. Монтируем
```
sudo mount /dev/vdb /mnt/pg-ext-data
```
5. Проверяем
```
df -h
```
# 4. Настройте PostgreSQL для работы с новым диском.
1. Выключаем сервер и переносим данные на внешний диск
```
sudo systemctl stop postgresql@18-main.service 
sudo mv /var/lib/postgresql/18/main /mnt/pg-ext-data/18
sudo chown -R postgres:postgres /mnt/pg-ext-data
```
2. Меняем конфиг
```
sudo nano /etc/postgresql/18/main/postgresql.conf
data_directory = '/mnt/pg-ext-data/18'
```
3. Запускаем сервис
```
systemctl start postgresql@18-main.service
```
