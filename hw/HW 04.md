## Patrony

### Устанавливаем пакеты postgresql
```
sudo apt install postgresql -y
```
### Устанавливаем пакеты patroni
В Debian 13 пакет `patroni` доступен в основном репозитории (версия 4.0.7 или новее)
```
sudo apt install patroni
sudo apt install python3-etcd python3-etcd3 python3-etcd3gw
```

Останавливаем postgresql на всех нодах, настраиваем конфигурацию, чистим раздел

```
systemctl stop postgresql@17-main

nano /etc/postgresql/17/main/postgresql.conf

listen_addresses = '*'
wal_keep_size = 1GB

nano /etc/postgresql/17/main/pg_hba.conf

host    all             all             0.0.0.0/0            scram-sha-256
host    replication     all             0.0.0.0/0            scram-sha-256
```

На всех нодах:
```
systemctl stop postgresql
rm -rf /var/lib/postgresql/17/main/*
```

### Проблемы и решения
В ходе запуска были проблемы в конфиг файле. После их исправления рекомендуется сделать
```
sudo rm -rf /var/lib/postgresql/17/main.failed
sudo rm -rf /var/lib/postgresql/17/main/*
```

На любой ноде с etcd выполнить (**только один раз**)
Поскольку etcd — это распределенное хранилище, данные синхронизируются между всеми тремя узлами автоматически. Как только удалим ключ на одном узле, информация мгновенно обновится на остальных.
```
etcdctl --endpoints=http://192.168.20.150:2379,http://192.168.20.151:2379,http://192.168.20.152:2379 del /service/postgres-cluster --prefix
```

### Переведем запуск в фоновый режим
1. Останавливаем `sudo -u postgres /usr/bin/patroni /etc/patroni/config.yml`

postgresql:

исправлено на

postgresql:
  listen: "192.168.20.160,127.0.0.1"
