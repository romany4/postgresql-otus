# 2. Настройка pg_probackup

## Создаем каталог для хранения резервных копий

```
sudo sh -c 'back=/var/back_postgres; mkdir $back ; chmod 755 $back ; chown postgres: $back'
```

## Инициализируем созданный каталог для backup:

```
sudo -u postgres pg_probackup-17 init -B /var/back_postgres
INFO: Backup catalog '/var/back_postgres' successfully initialized
```

## Добавляет instance
```
sudo -u postgres pg_probackup-17 add-instance --instance 'main' -D /var/lib/postgresql/17/main -B /var/back_postgres
INFO: Instance 'main' successfully initialized
```

```
ls -al /var/back_postgres/
```

Обратим внимание на предупреждение, которое выдал pg_probackup — на нашем кластере не включена проверка контрольных сумм, таким образом, он не может проверить блоки данных на корректность. Другими словами мы не защищены от того, что сбойные блоки данных не попадут в бэкап. (из [статьи на Хабре](https://habr.com/ru/companies/barsgroup/articles/515592/))

# 3. Новый кластер и перенос данных

```
 pg_lsclusters
Ver Cluster Port Status Owner    Data directory              Log file
17  main    5432 online postgres /var/lib/postgresql/17/main /var/log/postgresql/postgresql-17-main.log
17  test    5433 online postgres /var/lib/postgresql/17/test /var/log/postgresql/postgresql-17-test.log

```

## удаляем каталог с данными в кластере **test**, восстанавливаем из полной копии кластера **main**
```
rm -rf /var/lib/postgresql/17/test
```

```
sudo -u postgres pg_probackup-17 restore --instance 'main' -i 'T4LCZA' -D /var/lib/postgresql/17/test  -B '/var/back_postgres'
```

Подключаемся к test
```
	psql -p 5433
```

```
postgres=# \c some_database
You are now connected to database "some_database" as user "postgres".
some_database=# select count(*) from test;
 count
-------
   100
(1 row)

```

## Дольем данными из инкремента
```
rm -rf /var/lib/postgresql/17/test
sudo -u postgres pg_probackup-17 restore --instance 'main' -i 'T4LDJ3' -D /var/lib/postgresql/17/test -B '/var/back_postgres'
```

И убедимся что данные обновились
```
	psql -p 5433
```

```
postgres=# \c some_database
You are now connected to database "some_database" as user "postgres".
some_database=# select count(*) from test;
 count
-------
   200
(1 row)

```
