```
sudo sed -i '/^host/s/ident/md5/' /etc/postgresql/17/main/pg_hba.conf
sudo sed -i '/^local/s/peer/trust/' /etc/postgresql/17/main/pg_hba.conf
echo "host all all 0.0.0.0/0 md5" | sudo tee -a /etc/postgresql/17/main/pg_hba.conf
```
Рестартим службу

# 5. Работа с транзакциями

Выключим автоматический коммит (auto commit) в обеих сессиях.
```
#\set AUTOCOMMIT OFF
```
В первой сессии создаем таблицу shipments (перевозки) и добавляем в неё данные
```
postgres=# create table shipments(id serial, product_name text, quantity int, destination text);
CREATE TABLE
postgres=# select * from shipments;
 id | product_name | quantity | destination
----+--------------+----------+-------------
(0 rows)
```

```
postgres=# insert into shipments(product_name, quantity, destination) values('bananas', 1000, 'Europe');
insert into shipments(product_name, quantity, destination) values('coffee', 500, 'USA');
commit;
INSERT 0 1
INSERT 0 1
COMMIT

```

Проверяем уровень изоляции в обеих сессиях
```
postgres=# SHOW transaction isolation level;
 transaction_isolation
-----------------------
 read committed
(1 row)

```

# 6. Изучение уровней изоляции
- В первой сессии добавьте новую запись:
    
    ```
    insert into shipments(product_name, quantity, destination) values('sugar', 300, 'Asia');
    ```
    
- Во второй сессии выполните:
    
    ```
    select * from shipments;
    ```
Новых данных нет, так как в первой сессии транзакция не была завершена.

Выполняем commit
```
postgres=*# commit;
COMMIT
```
Во второй сессии данные появились. При завершении транзакции в первой сессии изменения стали доступны во второй сессии.
```
postgres=*# select * from shipments;
 id | product_name | quantity | destination
----+--------------+----------+-------------
  1 | bananas      |     1000 | Europe
  2 | coffee       |      500 | USA
  3 | sugar        |      300 | Asia
(3 rows)

```

# 7. Эксперименты с уровнем изоляции Repeatable Read
На обеих сессиях выполняем
```
postgres=# set transaction isolation level repeatable read;
```

```
postgres=*# show transaction isolation level;
 transaction_isolation
-----------------------
 repeatable read
(1 row)

```

В первой сессии добавляем новую строку
```
postgres=*# insert into shipments(product_name, quantity, destination) values('bananas', 2000, 'Africa');
INSERT 0 1
```

Проверяем во второй сессии
```
postgres=*# select * from shipments;
 id | product_name | quantity | destination
----+--------------+----------+-------------
  1 | bananas      |     1000 | Europe
  2 | coffee       |      500 | USA
  3 | sugar        |      300 | Asia
(3 rows)
```
Новой строки не видно, потому что при `repeatable read` при открытии второй транзакции ей доступны данные такого снимка данных, который был на момент открытия транзакции.
Даже после того, как сделаем commit в первой сессии данные не появятся, т.к. при открытии второй транзакции ей доступны данные того снимка, который был на момент открытия транзакции.
Данные во второй сессии появятся только после выполнения commit.
```
postgres=*# commit;
COMMIT
postgres=# select * from shipments;
 id | product_name | quantity | destination
----+--------------+----------+-------------
  1 | bananas      |     1000 | Europe
  2 | coffee       |      500 | USA
  3 | sugar        |      300 | Asia
  4 | bananas      |     2000 | Africa
(4 rows)

```
Cтал доступен свежий снимок данных и теперь мы можем увидеть все изменения.
