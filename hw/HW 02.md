# Разверните контейнер с PostgreSQL 14, смонтировав в него /var/lib/postgres.

В директории создадим `docker-compose.yml`
```
version: '3.9'

services:
  postgres:
    image: postgres:14.18-alpine
    container_name: postgres_container
    environment:
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: postgres
      POSTGRES_DB: db
      PGDATA: /var/lib/postgresql/data/pgdata
    ports:
      - "5432:5432"
    volumes:
      - ./pgdata:/var/lib/postgresql/data/pgdata
```
И запустим
```
docker compose up -d
```

Проверим `docker ps`
```
CONTAINER ID   IMAGE                   COMMAND                  CREATED          STATUS          PORTS                                         NAMES
0c2033d0d0d2   postgres:14.18-alpine   "docker-entrypoint.s…"   31 seconds ago   Up 20 seconds   0.0.0.0:5432->5432/tcp, [::]:5432->5432/tcp   postgres_container
```
Пробуем подключиться
```
psql -U postgres -d postgres -h 89.169.191.244
Command 'psql' not found, but can be installed with:
apt install postgresql-client-common
```
На этой виртуалке не поставлен postgres. Для выполнения ДЗ поставим postgresql-client
```
sudo apt install postgresql-client
```
Пробуем еще раз подключиться
```
psql -U postgres -d postgres -h 89.169.191.244
Password for user postgres:
psql (16.10 (Ubuntu 16.10-0ubuntu0.24.04.1), server 14.18)
Type "help" for help.

```

Успешное подключение.
